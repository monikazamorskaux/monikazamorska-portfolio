Project overview

Mall clients using Placewise's CMS needed a way to mix different types of content — events, articles, deals — on a single page section, with both manual curation and automatic fallback. No existing block could do this.

I designed a new Mixed Content block for MPC — flexible enough to handle every content combination clients needed, with four layout options, publication scheduling, display limits, and a drag-and-drop content list mixing pinned items with automatic conditions. It's now the most-used block in the platform.

01 — Understanding

The gap
in MPC.

MPC (Mall Publishing Console) is Placewise's CMS — the tool mall clients use to build and manage their websites. Clients can add content blocks to pages, each block displaying a specific type of content: events, articles, deals, offers.

The problem: real editorial needs don't respect content type boundaries. A client wants to feature "the 3 most important things happening right now" — which might be two events and a deal. Or they want to pin a specific article at the top, then fill the rest automatically. None of the existing blocks could do this.

Client need
Mix content types in one section

Clients wanted to feature events alongside articles, deals next to news — in one cohesive block. Existing blocks were single-type only, forcing workarounds or leaving the need unmet.

Editorial control
Pin specific items + auto-fill

Clients wanted both: the ability to manually feature a specific piece of content (a pinned event, a promoted article) and have the rest filled automatically from a category or tag condition.

Flexibility target
One block to cover all cases

Rather than building multiple narrow blocks, the goal was a single, composable block that could adapt to any client's content strategy — from a simple grid to a curated teaser section.

02 — Design

One block,
many forms.

The block needed to expose significant configuration power without overwhelming less technical users. The solution: a modal-based configuration panel with clearly separated concerns — general settings, layout choice, display limits, and content composition — each section independent but linked.

mpc.placewise.com / pages

Empty state — new block configuration. General info (title, internal label, publication dates), layout selector (Grid / Carousel / List / Teaser), display limits, and the content area awaiting input.

mpc.placewise.com / pages

Filled state — block configured with mixed content. A Condition (auto-fill: Articles + Deals + Events by tag), a pinned Custom item, a specific CMS item, and another Condition as fallback. Up to 12 items and conditions.

Content composition
Three item types, mixed freely
  • Condition — auto-fills from a category/tag filter (e.g. "newest sport articles"). Max items configurable.
  • Custom item — manually created content not in the CMS (headline + image)
  • CMS item — a specific piece of existing content pinned by the editor
Layout options
Four display modes
  • Grid — standard multi-column grid, most common
  • Carousel — horizontal scroll, good for feature sections
  • List — stacked rows, editorial/news style
  • Teaser (3-element) — compact spotlight view for hero-adjacent placement
Design principle

Create one flexible block that lets editors handle every content display scenario with ease — including built-in fallback logic.

03 — Outcome

Most-used
block.

The Mixed Content block shipped and quickly became the most-used block in MPC across all clients. It replaced multiple narrow workarounds and became the default way clients build content sections on their mall websites.

Adoption
Most-used block in MPC

After launch it became the go-to block for clients building content pages — replacing a fragmented set of single-type blocks and editorial workarounds.

Flexibility validated
Every use case covered

The combination of conditions, pinned CMS items, and custom items covered all the content scenarios clients had been requesting — without needing additional block types.

Design impact
Composable pattern established

The mixed content model — manual curation + automatic fallback — became a reference pattern for subsequent block design in MPC, influencing how other configurable blocks were structured.

One block replaced a fragmented workaround ecosystem.
By designing a single, composable block that mixed editorial curation with automatic content conditions, the Mixed Content block eliminated the gap between what clients needed and what MPC could provide — and became the platform's most-used component in the process.
